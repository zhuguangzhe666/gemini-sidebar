## 🚀 我的 Gemini 助手 (Eric's Edition) 使用说明

**简介：** 欢迎使用您定制的“我的 Gemini 助手” Chrome 插件！这款强大而个性化的工具，能将 Google 最新的 Gemini AI 模型深度集成到您的浏览器侧边栏。无论您是需要快速解答问题、高效总结文章、实时翻译文本，还是对网页内容进行深度分析，只需轻轻划词或在侧边栏输入，您的 AI 助手便能随时提供帮助。它旨在提升您的浏览和信息处理效率，让智能助手触手可及。

---

### 一、 插件安装教程

在您的 Chrome 浏览器中加载这款插件非常简单，只需几步：

1.  **打开扩展程序管理页面：**
    * 在 Chrome 浏览器地址栏输入 `chrome://extensions/` 并回车。
    * 或者，点击浏览器右上角的**三个点**（⋮）-> **更多工具** -> **扩展程序**。
2.  **开启开发者模式：**
    * 在扩展程序页面的**右上角**，找到并**打开“开发者模式”**开关。
3.  **加载已解压的扩展程序：**
    * 点击页面左上角的 **“加载已解压的扩展程序”** 按钮。
    * 在弹出的文件选择窗口中，**选择您的插件所在文件夹的根目录**（即包含 `manifest.json`、`sidepanel.html`、`background.js` 等文件的那个文件夹）。
    * 点击“选择文件夹”。
4.  **固定插件图标（可选但推荐）：**
    * 加载成功后，您会在浏览器右上角的工具栏看到一个**拼图状的图标**。
    * 点击这个拼图图标，找到“我的 Gemini 助手”，然后点击旁边的**图钉图标**，将其固定到工具栏，方便快速访问。

### 二、 首次设置：获取 Google Gemini API 密钥

在使用插件前，您必须先获取一个 Google API 密钥。这个密钥是插件与 Google AI 服务通信的“钥匙”。

**重要提示：**

* **无需启用任何额外 API：** 您的 Gemini API 密钥通常在创建后即可使用，无需在 Google Cloud Console 中手动启用其他服务。
* **无需关联结算账号：** 对于个人日常使用，Google Gemini API 提供了 generous 的免费额度，通常不需要关联结算账号。
* **密钥非一次性：** 您获得的密钥可以重复使用，并非一次性的。但请务必妥善保管，不要泄露。

**步骤 1：访问 Google AI Studio**

* 打开浏览器，访问 `https://ai.google.dev/`。
* 使用您的 Google 账号登录。

**步骤 2：创建 API 密钥**

1.  登录后，点击页面左侧的 **"Get API key"**（获取 API 密钥）。
2.  在 "API keys" 页面，点击 **"Create API key"**（创建 API 密钥）。
3.  系统会提示您将密钥保存在一个 **Google Cloud 项目** 中。

**步骤 3：创建 Google Cloud 项目（首次用户一次性操作）**

1.  在弹出的窗口中，点击 **"Create new project"**（创建新项目）。
2.  为您的项目命名：
    * **项目名称 (Project Name):** 输入一个您能看懂的昵称，例如 `Erics Gemini Plugin`。
    * **项目 ID (Project ID):** 系统会自动生成一个唯一的 ID。**您直接使用自动生成的即可。**
3.  **位置 (Location):** **请务必选择 "无组织" (No Organization)**。这是个人开发者的标准选项。
4.  点击“创建项目”。

**步骤 4：复制您的密钥**

1.  项目创建成功后，系统会自动为您生成一长串字符（通常以 `AIza...` 开头）。
2.  **这就是您的 API 密钥！**
3.  **请立即点击“复制”**。您获得的密钥可以重复使用。

### 三、 插件配置：连接您的助手

获取密钥后，就可以激活插件了。

1.  在 Chrome 浏览器右上角，点击您的插件图标，侧边栏会滑出。
2.  点击侧边栏右上角的**设置图标（⚙️）**。
3.  您会看到展开的设置面板：
    * **API 密钥：** 将您刚刚复制的 `AIza...` 密钥粘贴到这里。
    * **AI 模型：** 在下拉框中选择您希望使用的模型。
        * **Pro (Pro - 高质量):** 功能最强，回答质量最高。
        * **Flash-pre (Flash-pre - 平衡):** 速度和质量的平衡点（预览版）。
        * **Flash-lite-pre (Flash-lite-pre - 最快):** 响应速度最快，适合快速查询（预览版）。
    * **保存密钥：** 点击此按钮保存您的密钥。
    * **模型切换：** 切换模型后，设置会自动保存。

### 四、 功能使用：释放全部潜力

#### 1. 常规聊天

* 在底部的输入框中输入任何问题。
* 按下 **`Enter` (回车键)** 即可发送。
* 如果想在输入框内**换行**，请按 **`Shift + Enter`**。

#### 2. 划词提问（核心功能）

1.  在任何网页上，用鼠标选中（高亮）一段您感兴趣的文本。
2.  在选中的文本上**单击鼠标右键**。
3.  在弹出的菜单中，点击 **"✨ 用 Gemini 助手提问: "..."** 选项。
4.  侧边栏会自动打开（如果尚未打开）。
5.  您会看到，在输入框的**正上方**出现了一个“**引用框**”，里面显示着您刚刚划选的文本。

#### 3. 处理引用内容

当“引用框”显示时，您的下一次提问将会结合引用的内容：

* **提问 + 引用：** 在输入框中输入您的问题（例如：“总结这段话。”或“翻译成中文”），然后按 `Enter`。AI 会基于引用内容来回答您的问题。
* **仅引用：** 如果您不输入任何问题，**直接按 `Enter`**，AI 会对引用内容执行一个默认操作（例如：总结或分析）。
* **清除引用：** 如果您不想使用这段引用了，只需点击引用框右侧的**清除按钮（✖️）**即可。

#### 4. 切换主题

* 点击侧边栏右上角的**月亮（🌙）**或**太阳（☀️）**图标，可以在赛博朋克（暗黑）和白日（亮色）主题之间自由切换。
* 您的主题偏好会自动保存。

### ❓ 常见问题 (FAQ) 和故障排除

* **Q: 我划词了，但点击右键没反应/侧边栏没引用？**
    * A: **修复说明：** 请确保您在 `chrome://extensions/` 页面中，找到“我的 Gemini 助手”插件，并点击其旁边的**刷新按钮（一个圆圈箭头）**。这通常能解决大部分功能加载问题。如果问题依旧，请检查 `background.js` 文件是否已保存并刷新。
* **Q: 我点击浏览器工具栏上的插件图标，侧边栏没反应？**
    * A: **修复说明：** 同上，请在 `chrome://extensions/` 页面刷新插件。插件加载时，Chrome 会自动将图标点击事件与侧边栏的打开/关闭绑定。
* **Q: 我发送消息，但返回 `API 调用失败: HTTP 错误! 状态: 404`。**
    * A: 这意味着您在“设置”中选择的 **AI 模型 ID 是无效的**。请检查您在 `sidepanel.html` 中 `model-select` 的 `<option value="...">` 是否是 Google AI Studio 或 Gemini API 文档中确认支持且拼写完全正确的模型 ID。
* **Q: 我发送消息，但返回 `API 调用失败: HTTP 错误! 状态: 400` 或 `403`。**
    * A: 这 99% 意味着您的 **API 密钥是错误的、过期了，或者存在权限问题**。请仔细检查您在“设置”中输入的 API 密钥是否与从 Google AI Studio 复制的一致。如果问题依旧，尝试在 Google AI Studio 中**重新生成一个 API 密钥**并更新。
* **Q: 插件安装后，浏览器提示“此扩展程序可能包含恶意软件”？**
    * A: 这是因为您以“开发者模式”加载了本地插件，Chrome 的安全警告会比较积极。由于这是您自己构建和维护的插件，并且代码透明可见，因此可以**忽略此警告**。这并非真正的恶意软件，只是 Chrome 对未从官方商店安装的插件的通用提示。
* **Q: 我会不会超额度？什么是 RPM/TPM/RPD？**
    * A: 对于个人日常使用，您**几乎不会超额度**。Google Gemini API 提供 generous 的免费额度。以下是**免费层级的标准限制**：
        * **RPM (Requests Per Minute - 每分钟请求数):**
            * `gemini-1.5-pro`: **2** 次
            * `gemini-1.5-flash`: **10** 次
            * `gemini-1.5-flash-lite`: **15** 次
        * **TPM (Tokens Per Minute - 每分钟令牌数):**
            * `gemini-1.5-pro`: **125,000** 令牌
            * `gemini-1.5-flash`: **250,000** 令牌
            * `gemini-1.5-flash-lite`: **250,000** 令牌
        * **RPD (Requests Per Day - 每天请求数):**
            * `gemini-1.5-pro`: **50** 次
            * `gemini-1.5-flash`: **250** 次
            * `gemini-1.5-flash-lite`: **1,000** 次
    * 您可以在 Google AI Studio 的 API 密钥管理页面查看您的实时使用情况。通常，个人用户的使用量远低于这些限制，您可以放心地使用助手。
